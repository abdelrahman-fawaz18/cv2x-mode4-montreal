# Figures

## Maps

`maps/` contains OpenStreetMap views and SUMO network views for the city-center and lower-density Montreal scenarios. The cropped `*-panel` files are used on the repository landing page; the larger screenshots retain the complete application views.

Map data and imagery require the attribution **© OpenStreetMap contributors**. See [NOTICE.md](../NOTICE.md) for license information.

## Results

`results/` contains the final PRR and mean-CBR comparison plots used to summarize the experiment.
