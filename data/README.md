# Data

`raw/` contains two representative OMNeT++ `scavetool` exports stored as gzip files. Compression keeps each file below GitHub’s single-file limit with the original CSV bytes unchanged.

The CSV configuration metadata links:

- `Map1.csv.gz` to `highway/006vpm/mtl.launchd.xml`;
- `Map2.csv.gz` to `highway/2006vpm/mtl.launchd.xml`.

See [raw/README.md](raw/README.md) for file sizes, checksums, and decompression commands.
